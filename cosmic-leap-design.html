The 7 Aether Galaxies
🧭 Design Philosophy

Each galaxy introduces one core gravity mechanic that builds on the last. Difficulty scales by forcing players to combine mechanics from previous worlds. World 7 — The Core — reuses all prior mechanics simultaneously. Solo and co-op modes share the same geometry but unlock branching paths that require two players to access.

Technical Architecture
Full Stack Breakdown
🏗️ Architecture Principle

Server-authoritative design throughout. The client renders only — all game state, token transactions, match results, and anti-cheat validation happen server-side. No client value is trusted without server confirmation. This prevents token cheating, speedhacking, and result manipulation.

Multiplayer Netcode — Rollback Architecture
🔐 Anti-Cheat Strategy

Three-layer protection: (1) Client-side — Easy Anti-Cheat scans for memory injection and DLL hijacking. (2) Network-layer — Server rejects any physics state that violates velocity caps or teleportation thresholds. (3) Economy-layer — All shard mutations are signed server transactions logged to an append-only ledger; any unsigned client shard claim is silently discarded.
